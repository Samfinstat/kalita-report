# КАЛИТА — Маркетинговый отчёт

Автоматически обновляемый отчёт по контекстной рекламе и SEO.  
Доступ по паролю. Публикуется через GitHub Pages.

## 🚀 Деплой на GitHub Pages (один раз)

1. Создайте новый репозиторий на [github.com](https://github.com)  
   Название: `kalita-report` (или любое другое)  
   Поставьте: **Private** (если хотите скрыть код) или Public

2. Загрузите файлы в репозиторий:
   ```
   kalita-report/
   ├── index.html       ← главный отчёт
   ├── data/
   │   └── metrics.json ← данные для обновления
   └── README.md
   ```

3. Перейдите в **Settings → Pages**  
   Source: `Deploy from a branch`  
   Branch: `main` / `root`  
   Нажмите **Save**

4. Через 1–2 минуты отчёт будет доступен по адресу:  
   `https://ВАШ_ЛОГИН.github.io/kalita-report/`

## 🔑 Пароль доступа

Текущий пароль: **`kalita2026`**

Чтобы изменить пароль — откройте `index.html` и найдите строку:
```javascript
const PASSWORD = 'kalita2026';
```
Замените значение на новый пароль и загрузите файл в репозиторий.

## 📅 Ежемесячное обновление данных

Каждый месяц выполните следующее:

### Шаг 1: Скачайте новые отчёты из Яндекс.Директ и Яндекс.Вебмастер

### Шаг 2: Запустите скрипт обновления
```bash
pip install pandas openpyxl
python update_data.py --spend НОВЫЙ_ФАЙЛ_ДИРЕКТ.xlsx --seo НОВЫЙ_ФАЙЛ_SEO.xlsx
```

### Шаг 3: Обновите файл на GitHub
Замените `index.html` в репозитории новым файлом.  
GitHub Pages автоматически обновит сайт.

## 📊 Структура данных

Все показатели хранятся прямо в `index.html` в разделе `<script>`:
```javascript
const months = ['Дек 2025','Янв 2026','Фев 2026','Мар 2026','Апр 2026'];
const spend  = [38277, 38676, 66041, 88522, 17894];
const convs  = [6, 15, 32, 27, 5];
```

При добавлении нового месяца — просто добавьте значение в конец каждого массива.

## 🛡️ Безопасность

Пароль хранится в JavaScript на стороне клиента.  
Это обеспечивает базовую защиту от случайных посетителей.  
Для высокого уровня защиты используйте Netlify с server-side аутентификацией.
