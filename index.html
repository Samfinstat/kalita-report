Выводы

📊 Итоговая динамика

Август стал лучшим месяцем за весь период работы. Запущен новый формат рекламы — товарная кампания с показом карточек продукции. По данным CRM за месяц зафиксировано 119 качественных обращений от потенциальных покупателей на сумму 770 770 рублей — рекордный результат.

Стоимость привлечения одного клиента снизилась до 961 рубля — это в разы лучше показателей всех предыдущих месяцев. Почти половина всех входящих обращений (47%) оказывается качественной заявкой — очень высокий показатель для B2B-сегмента. Точная доля новых клиентов среди этих обращений уточняется — часть могла прийти от уже действующих партнёров.

Позиции сайта в поисковой выдаче Яндекса по Санкт-Петербургу остаются сильными — по ключевым запросам («биг бэги оптом», «производство мешков биг бэг» и другим) КАЛИТА держится на первой позиции. В сентябре продолжаем развивать новый рекламный формат — он показал себя как главный источник роста — и восстанавливаем поисковую рекламу по остальным направлениям.

🔤 Семантика — матрица решений
Масштабировать — данные подтверждают
  • Товарная кампания — CPA 443₽, CR 10.71% — расширять фид и бюджет в приоритете
  • Ретаргетинг — первая конверсия по CPA 295₽, накапливать аудиторию дальше
Урезать / пересмотреть — расход без результата
  • РСЯ — CPA 23 733₽, стабильно неэффективна 5 месяцев подряд
  • ПОСИК МКР — CPC 567₽ аномален, приостановить до калибровки ставок
Наблюдать — мало данных, не трогать
  • биг бэги с вкладышем, с клапаном — ждём ≥30 кликов для вывода
  • биг бэги для зерна, для песка — недостаточно статистики
Следующим этапом — запланировать
  • Перезапуск ПОИСК БИГ-БЭГ с тестовым бюджетом 20-25K₽
  • Расширение фида Товарной кампании — больше SKU в ленту
  • Гео-тест: Ленинградская область — отдельный бюджет после стабилизации МКР
⚠️ Правило семантики: новые фразы добавляем только от рабочих веток, не «во все стороны». Смена заголовков и текстов объявлений — только когда CTR упал ниже 4% в поиске и это подтверждено за 14+ дней. Иначе не трогать.
🎯 Стратегия
Текущая фаза
Масштабирование МКР
Тест пройден (дек–янв), данные накоплены, рабочий кластер найден. Задача — увеличить объём МКР без потери CPA, не распыляясь на слабые направления.
Следующая фаза
Диверсификация
Когда МКР: стабильно ≥25 конверсий/мес при CPA ≤ 3 500 ₽ → подключать ПП-масштаб, ретаргетинг, гео. До этого не дёргать структуру.
Яндекс.Метрика — обязательный минимум
  • Цели по воронке: клик на номер → заявка → подтверждение — 3 отдельные цели, не одна общая
  • Сегмент «конвертировавшие» → look-alike для РСЯ расширения
  • Сегмент «посетители МКР-страниц ≥ 2 мин» → ретаргетинг в РСЯ с повышенной ставкой
  • Сегмент «отказники с мобильных» → понижающая корректировка -30% на мобильные в поиске
  • Еженедельно: Источники → Директ + глубина просмотра по кампаниям — выявлять деградацию качества
CRM-связка — запросить у клиента
  • Уточнить: есть ли CRM (Битрикс24, amoCRM, другая) → если да — настроить передачу yclid в CRM
  • Цель в Директе привязать к реальной сделке в CRM, не к техническому срабатыванию на сайте
  • Если CRM нет — минимум коллтрекинг (Calltouch, CoMagic) для разделения звонков по кампаниям
  • Через 2–3 мес CRM-данных → пересчитать реальный CPA и ROI по каждому кластеру
  • КАЛИТА сейчас: конверсии по целям сайта — уточнить у клиента % реальных лидов от технических
Принципы — не нарушать
  • Данные первичны. Изменения объявлений, текстов, картинок — только когда цифры требуют. CTR упал ниже порога за 14+ дней? Тест. Иначе — не трогать.
  • ≥30 кликов на кластер до любого вывода об эффективности. До 30 кликов — наблюдение без действий.
  • Один эксперимент за раз. Менять ставки и семантику одновременно — теряем понимание причины результата.
  • Метрика и CRM — всегда. Директ без Метрики — слепой полёт. Запрашивать доступ в первые 2 недели работы с любым клиентом.
  • Сезонность учитывать заранее. За 3–4 нед до пика (апрель–май) — готовить расширение. За 3–4 нед до спада (ноябрь) — снижать ставки.
