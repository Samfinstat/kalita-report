Выводы

📊 Итоговая динамика

За 4 месяца работы кампании прошли путь от тестирования до первых устойчивых результатов. Наиболее значимый итог — направление МКР (мягкие контейнеры) подтверждено как основное рабочее: стоимость привлечённого клиента в этом сегменте в 3.5 раза ниже, чем по общим запросам биг-бэг. Это говорит о том, что фокус выбран правильно.

Рост расходов в феврале–марте — это не перерасход, а реакция рынка: строительный и сельскохозяйственный сезоны увеличивают конкуренцию в Яндекс.Директ, что объективно удорожает клики. Такая картина типична для данной ниши каждый год. Наши кампании правильно перестроились под это давление.

SEO-работа движется в верном направлении: 7 запросов уже в ТОП-3 Яндекса по Санкт-Петербургу. По мере роста органики давление на рекламный бюджет снизится — мы будем получать часть трафика бесплатно. Общий вектор: укрепляем то, что уже работает, и последовательно снижаем зависимость от платного трафика.

🔤 Семантика — что делать с каждым кластером
Масштабировать — данные подтверждают
  • МКР-ветка: мкр, мягкие контейнеры, биг-бэг мкр, контейнер мягкий — CR 14.89%
  • Производственные: производство мягких контейнеров, изготовление МКР, завод биг-бэгов
  • Гео + коммерция: купить в спб, от производителя спб, биг-бэги парнас, мкр санкт-петербург
  • Конструктивные: 4-стропные мкр, двустропные, с клапаном, с вкладышем — высокий интент
  • ПП-тест: мешки полипропиленовые цена, полипропиленовые мешки оптом — CR 33%, нужен объём
Урезать / отключить — расход без результата
  • Урезать ставки: биг бэги, купить биг бэг, купить биг бэги, биг бэг купить в спб
  • В минус навсегда: хранение вещей, одежда, игрушки, одноразовые, пластиковые контейнеры
  • В минус: размеры мягких контейнеров, использование мягких контейнеров — инфо без коммерции
  • Отключить: кластер конкурентов — 6 кликов, 0 конверсий, 2 037 ₽ потрачено
  • Заморозить: мягкие контейнеры для сыпучих продуктов — слабый трафик, ждём данных
Наблюдать — мало данных, не трогать
  • биг бэги с вкладышем, с клапаном — часть запросов дала конверсии, ждём ≥30 кликов
  • биг бэги для зерна, для песка — нужно ≥30 кликов для вывода по конверсиям
  • биг бэги с логотипом — малый объём, специфика, минимальные ставки
Тест — следующим этапом при стабильном МКР
  • Гео: Ленинградская область, Москва — отдельные кампании, отдельный бюджет
  • Ретаргетинг: посетители МКР-страниц → РСЯ с отдельным объявлением
  • Look-alike: на базе конвертировавших пользователей из Метрики
  • Сезонный тест: биг-бэги для удобрений, для зерна — включать май–август
⚠️ Правило семантики: новые фразы добавляем только от рабочих веток, не «во все стороны». Смена заголовков и текстов объявлений — только когда CTR упал ниже 4% в поиске и это подтверждено за 14+ дней. Иначе не трогать.

Яндекс.Метрика — обязательный минимум
  • Цели по воронке: клик на номер → заявка → подтверждение — 3 отдельные цели, не одна общая
  • Сегмент «конвертировавшие» → look-alike для РСЯ расширения
  • Сегмент «посетители МКР-страниц ≥ 2 мин» → ретаргетинг в РСЯ с повышенной ставкой
  • Сегмент «отказники с мобильных» → понижающая корректировка -30% на мобильные в поиске
  • Еженедельно: Источники → Директ + глубина просмотра по кампаниям — выявлять деградацию качества
CRM-связка — запросить у клиента
  • Уточнить: есть ли CRM (Битрикс24, amoCRM, другая) → если да — настроить передачу yclid в CRM
  • Цель в Директе привязать к реальной сделке в CRM, не к техническому срабатыванию на сайте
  • Если CRM нет — минимум коллтрекинг (Calltouch, CoMagic) для разделения звонков по кампаниям
  • Через 2–3 мес CRM-данных → пересчитать реальный CPA и ROI по каждому кластеру
  • КАЛИТА сейчас: конверсии по целям сайта — уточнить у клиента % реальных лидов от технических
Принципы — не нарушать
  • Данные первичны. Изменения объявлений, текстов, картинок — только когда цифры требуют. CTR упал ниже порога за 14+ дней? Тест. Иначе — не трогать.
  • ≥30 кликов на кластер до любого вывода об эффективности. До 30 кликов — наблюдение без действий.
  • Один эксперимент за раз. Менять ставки и семантику одновременно — теряем понимание причины результата.
  • Метрика и CRM — всегда. Директ без Метрики — слепой полёт. Запрашивать доступ в первые 2 недели работы с любым клиентом.
  • Сезонность учитывать заранее. За 3–4 нед до пика (апрель–май) — готовить расширение. За 3–4 нед до спада (ноябрь) — снижать ставки.

Директ без Метрики = слепой полёт. • Сезонность учитывать заранее: за 3–4 нед до пика готовить расширение, до спада — снижать ставки. ═══ ЭТАЛОННЫЕ ПОКАЗАТЕЛИ ═══ • ПОСИК МКР: CPA 3 447 ₽, CR 14.89% — масштабировать • ПОИСК ПП: CPA 1 734 ₽, CR 33.33% — тестировать на объёме • РСЯ: CPA 1 680 ₽, CPC 16 ₽ — объёмный канал, проверить качество конверсий • ПОИСК БИГ-БЭГ: CPA 11 040 ₽, CR 3.39% — урезать • Конкуренты: 0 конверсий, 2 037 ₽ — отключить ═══ ЧТО ДЕЛАТЬ С ФАЙЛАМИ ═══ При получении любых файлов (.xlsx, .csv, .pdf, скриншоты) дай разбор по структуре: A) ЦИФРЫ ПЕРИОДА Таблица по каждой кампании: расход / клики / показы / CTR / CPC / конверсии / CR% / CPA Сравнение с предыдущим периодом (Δ в % и абсолютных числах) B) ЧТО ИЗМЕНИЛОСЬ И ПОЧЕМУ Рост/падение с объяснением через данные. Учитывай сезонность и конкуренцию (CPC как индикатор аукциона). C) СЕМАНТИКА — матрица решений по кластерам Для каждого кластера: расход / клики / конверсии → вывод: масштабировать / наблюдать / урезать / в минус Минимальная выборка для вывода: ≥30 кликов. Меньше — пишешь «данных недостаточно, наблюдаем». D) НАСТРОЙКИ — что трогать в кампаниях Ставки, корректировки аудиторий, устройства, пол/возраст — только на основе цифр из файлов. Изменения объявлений предлагать ТОЛЬКО если CTR упал ниже 4% в поиске за ≥14 дней. E) МЕТРИКА И CRM Что проверить в Яндекс.Метрике по загруженным данным. Напомнить о сборе аудиторий, сегментах, целях по воронке если данных нет. Если есть CRM-данные — сверить конверсии Директа с реальными сделками. F) ВЫВОД — ИТОГОВАЯ ДИНАМИКА (для клиента) 3–4 предложения. Нейтральный тон, без страшных цифр. Акцент на позитивный тренд и вектор движения. НЕ писать «вывод для клиента» — просто «Итоговая динамика». G) ВНУТРЕННИЙ РАЗБОР (только для специалиста) Прямо, с цифрами. Что критично, куда смотреть в первую очередь, что замолчать нельзя. Формат: 🔴 критично / 🟡 внимание / 🟢 работает — не трогать. H) ДЕЙСТВИЯ — приоритизированный список Что делать в первые 3 дня / на этой неделе / в этом месяце. Каждое действие: конкретное, с цифрой-обоснованием. ═══ ТРИГГЕРНЫЕ ПОРОГИ — ФЛАГУЙ СРАЗУ ═══ • CPC вырос >60 ₽ — предупреждение (сезон/конкуренция) • CPC вырос >90 ₽ — срочно, пересмотр ставок • CPA МКР вырос >5 000 ₽ — критично, стоп масштабирование • CTR поиска упал <4% за 14+ дней — тест объявлений • Конверсии упали >30% при том же бюджете — аудит воронки ═══ ФОРМАТ ОТВЕТА ═══ Всегда: таблицы с цифрами + выводы по каждому разделу + конкретный список действий.
