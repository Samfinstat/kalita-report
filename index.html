📊 Итоговая динамика

Апрель принёс первые данные из CRM: зафиксировано 3 качественных лида на сумму 77 620 ₽ при общем бюджете 50 157 ₽ — это положительный результат для первого полного месяца. Кампании привлекают реальных покупателей, готовых к сделке.

Запущен ретаргетинг — новый инструмент для работы с посетителями сайта, которые не оставили заявку сразу. РСЯ-кампания продолжает давать стабильный поток обращений по низкой цене (CPA 1 331 ₽).

По SEO в апреле зафиксировано снижение позиций — ряд запросов потерял места в выдаче Яндекса. Сейчас задача — выяснить причину и восстановить ключевые страницы. Общий вектор: реклама работает эффективнее, SEO требует дополнительного внимания в мае.

🔤 Семантика — что делать с каждым кластером
Масштабировать — данные подтверждают
  • МКР-ветка: мкр, мягкие контейнеры, биг-бэг мкр, контейнер мягкий — CR 14.89%
  • Производственные: производство мягких контейнеров, изготовление МКР, завод биг-бэгов
  • Гео + коммерция: купить в спб, от производителя спб, биг-бэги парнас, мкр санкт-петербург
  • Конструктивные: 4-стропные мкр, двустропные, с клапаном, с вкладышем — высокий интент
  • ПП-тест: мешки полипропиленовые цена, полипропиленовые мешки оптом — CR 33%, нужен объём
Урезать / отключить — расход без результата
  • Урезать ставки: биг бэги, купить биг бэг, купить биг бэги, биг бэг купить в спб
  • В минус навсегда: хранение вещей, одежда, игрушки, одноразовые, пластиковые контейнеры
  • В минус: размеры мягких контейнеров, использование мягких контейнеров — инфо без коммерции
  • Отключить: кластер конкурентов — 6 кликов, 0 конверсий, 2 037 ₽ потрачено
  • Заморозить: мягкие контейнеры для сыпучих продуктов — слабый трафик, ждём данных
Наблюдать — мало данных, не трогать
  • биг бэги с вкладышем, с клапаном — часть запросов дала конверсии, ждём ≥30 кликов
  • биг бэги для зерна, для песка — нужно ≥30 кликов для вывода по конверсиям
  • биг бэги с логотипом — малый объём, специфика, минимальные ставки
Тест — следующим этапом при стабильном МКР
  • Гео: Ленинградская область, Москва — отдельные кампании, отдельный бюджет
  • Ретаргетинг: посетители МКР-страниц → РСЯ с отдельным объявлением
  • Look-alike: на базе конвертировавших пользователей из Метрики
  • Сезонный тест: биг-бэги для удобрений, для зерна — включать май–август
⚠️ Правило семантики: новые фразы добавляем только от рабочих веток, не «во все стороны». Смена заголовков и текстов объявлений — только когда CTR упал ниже 4% в поиске и это подтверждено за 14+ дней. Иначе не трогать.

  • Сегмент «конвертировавшие» → look-alike для РСЯ расширения
  • Сегмент «посетители МКР-страниц ≥ 2 мин» → ретаргетинг в РСЯ с повышенной ставкой
  • Сегмент «отказники с мобильных» → понижающая корректировка -30% на мобильные в поиске
  • Еженедельно: Источники → Директ + глубина просмотра по кампаниям — выявлять деградацию качества
CRM-связка — запросить у клиента
  • Уточнить: есть ли CRM (Битрикс24, amoCRM, другая) → если да — настроить передачу yclid в CRM
  • Цель в Директе привязать к реальной сделке в CRM, не к техническому срабатыванию на сайте
  • Если CRM нет — минимум коллтрекинг (Calltouch, CoMagic) для разделения звонков по кампаниям
  • Через 2–3 мес CRM-данных → пересчитать реальный CPA и ROI по каждому кластеру
  • КАЛИТА сейчас: конверсии по целям сайта — уточнить у клиента % реальных лидов от технических
Принципы — не нарушать
  • Данные первичны. Изменения объявлений, текстов, картинок — только когда цифры требуют. CTR упал ниже порога за 14+ дней? Тест. Иначе — не трогать.
  • ≥30 кликов на кластер до любого вывода об эффективности. До 30 кликов — наблюдение без действий.
  • Один эксперимент за раз. Менять ставки и семантику одновременно — теряем понимание причины результата.
  • Метрика и CRM — всегда. Директ без Метрики — слепой полёт. Запрашивать доступ в первые 2 недели работы с любым клиентом.
  • Сезонность учитывать заранее. За 3–4 нед до пика (апрель–май) — готовить расширение. За 3–4 нед до спада (ноябрь) — снижать ставки.
